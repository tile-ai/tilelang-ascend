# 多 kernel、AOT 与图链路计时

用于一次公开调用包含多个 kernel、AOT 动态库入口或 AclGraph replay 的算子。

1. 记录每个 case 的实际分支、核名、调用次数和源码版本。
2. 核对计时器如何聚合同名核及 AIC/AIV，避免漏计或重复计时。
3. 单核采集的 `launch-count` 是该核调用数；整链采集是所有匹配核的调用总数。
4. 整链验收调用真实公开入口，保留必要的转换、补零和临时空间开销。
5. 修改源码后重新确认入口、导入路径和核名，不复用旧内嵌实现。
6. 逐核采集只用于归因，不与公开入口的端到端结果混作同一口径。
7. 最终报告全部 case、预热与重复次数、缓存策略、异常轮次及独立复测结果。
8. JIT 入口先完成编译和预运行，再进入正式采集；AOT 入口记录 `.so`、构建命令和源码哈希。
9. AclGraph 同时标明测量的是单 kernel 还是完整 `replay()`，两种结果不能直接比较。
10. 如果现有入口已经提供 `--perf`、`--profiler msprof` 或 `bench.sh`，优先复用，不另造入口。

发现漏计时应废弃错误基线并重测，不通过修改公共计时器制造提升。
