# 固定小状态迭代归一化

> 迁移来源：Ascend950 同路径文档。保留可复用原文结构与门禁，仅改写 A2/A3 平台、后端、API、路径和证据范围。本页是设计/源码参考；本次未进行 NPU 编译、精度或性能验证，不继承950模板的验证状态。

适用于固定小矩阵或小张量上的多轮分组归一化及其反向传播。

**证据等级：A2/A3 设计参考，待目标 case 复验。** 源文记录该结构已有 Ascend 实现与实测，但没有为本仓 A2/A3 目标提供可复验的硬件、版本、命令和原始结果；本次只迁移通用设计，不继承源文的已实现/已实测等级。

## 优化结构

- 整个小状态跨多轮计算常驻 UB；若要求寄存器驻留，须先证明当前 A2/A3 lowering 能表达并保留该生命周期。局部维度优先保持逻辑访问轴，一维展开与多维布局须比较 lowering。
- 每个归一化组只计算一次倒数，再复用乘法；forward 不物化无用中间状态，backward 只保存反向需要的快照。
- barrier 只放在真实的跨阶段读写依赖处，不能从旧实现机械继承或删除。
- 片上驻留周期、局部布局、快照、同步点和展开代码量共同构成特征指纹；只复现其中一部分不得继承完整性能结论。

## 源文结构组合（A2/A3 待验证）

| 路径 | 待在 A2/A3 验证的物理结构 |
|---|---|
| 迭代归一化 | 二维 UB 状态跨整轮分组归一化常驻，每组只计算一次倒数；最终写出不添加无数据依赖的同步 |
| 反向重算与梯度传播 | 正向重算状态和反向梯度分别驻留，只保存反向真正需要的快照；仅在快照生产与消费之间同步 |

该组合只适用于完整状态可片上常驻的范围；其他规模须重新比较布局、代码量和实测性能。
